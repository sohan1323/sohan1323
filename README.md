## 👋 About Me

I'm **Sohan Shelar**, a cybersecurity enthusiast from **Pune, India**. I build small, focused, **zero-dependency command-line tools** that solve real security problems, from auditing Linux systems to checking password strength and protecting data at rest.

- 🔐 Exploring **defensive security**, threat detection and persistence monitoring
- 🐧 Working deep in **Linux internals**, shell scripting and system auditing
- 🧪 Applying **cryptography** the right way: strong key derivation, authenticated encryption
- 🌱 Currently learning: **advanced Linux security, secure coding, and IAM concepts**
- 🎯 Goal: turn practical security knowledge into clean, reusable open-source tools
